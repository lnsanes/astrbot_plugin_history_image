# astrbot_plugin_history_image

修一个很具体的问题：**被问「刚才那张图」时，图片已经不在上下文里了**。

QQ 机器人收到图片时，通常只把「[图片]」这个占位符放进对话历史，真正的图片 URL 存一会儿就过期。等用户过两轮再问「那张图是什么」，模型手上什么都没有。

## 做法

在发请求前，扫一遍历史消息，把**最近 N 张图片**重新附进 `req.prompt`，让模型重新看见它们。

```
用户：[图片] 这是什么
机器人：一只猫
用户：什么品种
        ↓
   （此时上下文里的图片已经只剩 [图片] 三个字）
        ↓
  插件从历史记录里取回原图，重新附上
        ↓
机器人：看起来是英短
```

## 无命令、无配置

装上就生效。

可调参数：回看多少条历史、最多附几张图、单张图是否降采样（控制 token）。
